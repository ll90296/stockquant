# StockQuant — 个股动量轮动信号引擎（自部署版）

部署在你自己服务器上的**信号引擎**：每天自动计算持仓信号并推送到微信/邮件，
你在券商 APP 里**手动下单**执行。全程不连接券商接口，**不构成程序化交易，无需报备**。

## 合规边界（务必阅读）

| 做法 | 合规性 |
|---|---|
| 服务器跑信号 + 推送，人工执行（每天 1 次或每周几次均可） | ✅ 合规，无需报备 |
| 券商 APP 条件单做防守（止损/提醒） | ✅ 合规，条件单走券商服务端 |
| 本软件直连券商柜台 / miniQMT / 第三方外挂自动下单 | ❌ 违规（2026-08-28 外接新规，个人被禁止且正在清退） |

## 安装

```bash
# 服务器要求: Python 3.10+, 能访问外网
git clone <本目录> stockquant && cd stockquant   # 或直接拷贝整个目录
pip install -r requirements.txt
python fetch_data.py        # 首次: 拉取沪深300成分股日线(~300只, 约10分钟)
```

## 配置（config.yaml）

- `strategy.lookback`：动量回看期（默认 120 个交易日）
- `strategy.top_n`：持仓只数（默认 5，5 万资金建议 4-6 只）
- `strategy.buffer_rank`：缓冲带（默认 10，已持仓股跌出前 10 才换出，压换手）
- `strategy.rebalance`：`weekly`（默认，回测最优）/ `daily` / `biweekly` / `monthly`
- `notify`：企业微信群机器人 webhook（推荐）/ Server酱 / SMTP 邮件，配一个即可

## 日常运行

```bash
# crontab -e 添加(每个交易日 17:10 运行):
10 17 * * 1-5  cd /path/to/stockquant && python run_daily.py --update >> logs/cron.log 2>&1
```

每天 17:10 自动：增量更新行情 → 判断是否调仓日 → 推送信号到微信。
调仓日推送内容：目标持仓（等权比例）+ 动量前 10 名；非调仓日只推送监测摘要。

## 执行与防守（券商 APP 内完成）

1. 收到调仓推送后，次日开盘手动卖出调出、买入调入（ETF 式等权，按 100 股整数倍）。
2. 对每只持仓挂 **-15% 跌幅止损条件单**（触发价 = 成本价 × 0.85）。
3. 账户级熔断：策略整体回撤 25% 时暂停执行，复盘后再恢复。

## 回测结果（沪深300成分 300 只，2018-01 ~ 2026-10，含全部成本）

| 频次 | 年化 | 最大回撤 | 夏普 | 年换手 | 总成本 |
|---|---|---|---|---|---|
| 每日 | +9.6% | -51.4% | 0.45 | 5.1x | 15.8% |
| **每周（默认）** | **+23.2%** | **-35.4%** | **0.85** | 3.2x | 9.7% |
| 每两周 | +19.4% | -37.0% | 0.74 | 2.6x | 7.9% |
| 每月 | +17.5% | -38.7% | 0.67 | 2.0x | 6.2% |

- 回看期稳健性：60/90/120/180 日全为正（+15.8% ~ +23.2%），120 日最优。
- **市场过滤是核心**：不开过滤时周频年化仅 +7.8%、回撤 -77%；开启后回撤压到 -35%。
- ⚠️ **重要偏差提示**：股票池用的是"当前"沪深300成分（幸存者偏差——赢家留在了池子里），回测收益**系统性偏高**；实盘预期应显著下调（打 5-7 折甚至更多）。本回测主要用来比较频次/参数的相对优劣，不是收益承诺。

```bash
python run_backtest.py      # 频次对比(daily/weekly/biweekly/monthly) + lookback 稳健性
```

成本模型：佣金万 2.5（最低 5 元）+ 卖出印花税万 5 + 滑点 0.1%。
每日频次跑输的两大原因：最低 5 元佣金对 5 万资金的小额调仓占比过高 + 换手成本累积。
